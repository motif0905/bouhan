# 日常防犯ナビ（仮称）

## システムの目的・ユニーク性
防犯に関する豆知識や統計データ、行動チェックを一つのWebアプリで分かりやすく提供し、日常生活の中で防犯意識を高められる点が特徴。

---

## 概要
日常防犯ナビは、防犯に関する知識や統計データを手軽に確認できるWebアプリです。  
防犯意識を高めたい個人や、地域全体の防犯意識向上を目的としています。

---

## 想定ユーザー
- 一般ユーザー（学生・社会人・高齢者など）
- 自治体・防犯団体
- 運営者（開発・コンテンツ管理者）

---

## 機能要件
- **豆知識表示機能**  
  防犯に関する豆知識をランダム表示・カテゴリ別閲覧
- **統計データ表示機能**  
  e-Stat APIを利用した統計データ表示
- **チェックリスト機能**  
  鍵の閉め忘れなど自分の防犯行動を記録・管理

---

## 非機能要件
- スマホで見やすく直感的に操作できる
- ページ表示時間を1秒以内にする

---

## 使用技術
- **フロントエンド**：Streamlit（Python）
- **バックエンド**：Python（処理・状態管理）
- **データ処理**：pandas（CSV/Excel読み込み・整形・集計）
- **データ保存**：CSVファイル
- **外部API**：e-Stat API
- **開発環境**：VS Code / GitHub / ブラウザ（Chrome推奨）
