# 日常防犯ナビ（仮称）

## システム概要
日常防犯ナビは、防犯に関する豆知識や統計データ、行動チェックを一つのWebアプリで分かりやすく提供し、日常生活の中で継続的に防犯意識を高めることを目的としたWebアプリです。現在は福岡県警が公開している防犯・犯罪統計データを活用し、将来的にはe-Stat APIを用いた全国対応への拡張を目指しています。

---

## システムの目的（課題解決）・ユニーク性
防犯に関する情報は分散しており、日常的に確認できる場が少ないという課題があります。本アプリでは、防犯の豆知識・統計データ・行動チェックを一元化し、日常生活の中で自然に防犯意識を高められる点を特徴としています。

---

## 想定ユーザー
- 防犯意識を高めたい一般ユーザー（学生・社会人・高齢者など）
- 地域の防犯意識向上を目的とする自治体・防犯団体
- 運営者（開発・コンテンツ管理者）

---

## 機能要件
- 豆知識表示機能  
  防犯に関する豆知識をランダム表示し、カテゴリ別に閲覧できる
- 統計データ表示機能  
  福岡県警が公開している防犯・犯罪統計データを加工し、分かりやすく表示する
- チェックリスト機能  
  鍵の閉め忘れや不審メール対応など、防犯行動を確認・記録できる

---

## 非機能要件
- スマートフォンでも見やすく、直感的に操作できるUI
- ページ表示時間は1秒以内を目標とする

---

## 使用技術
- フロントエンド：Streamlit（Python）
- バックエンド：Python（処理ロジック・状態管理）
- データ処理：pandas（CSV / Excelの読み込み、データ整形・集計）
- データ保存：CSVファイル
- データ提供元：福岡県警公開データ
- 開発環境：VS Code / GitHub / ブラウザ（Chrome推奨）

---

## システム構成
本アプリはStreamlitを用いた単一構成のWebアプリケーションです。  
アプリ内でCSVデータを読み込み・整形し、統計情報やチェックリストを表示します。  
統計データは福岡県警が公開しているデータを元に作成しています。
